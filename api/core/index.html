    Core API Reference

    Overview

    The QuantumMetaGPT core API provides the main entry points for quantum algorithm generation, evaluation, and optimization. All core functions require appropriate license validation.

    Main Classes

    PPOAgent

    Location: qmetagpt.quantum_algorithm_generator.agents.ppo_agent.PPOAgent

    License Required: Basic or higher

    Proximal Policy Optimization (PPO) agent for quantum circuit generation using reinforcement learning.

    Constructor

    PPOAgent(state_dim, action_dim, policy='MlpPolicy', **kwargs)

    Parameters: - state_dim (int): Dimension of the problem state space - action_dim (int): Dimension of the quantum gate action space
    - policy (str): Neural network policy type ('MlpPolicy', 'CnnPolicy') - **kwargs: Additional PPO hyperparameters

    Example: 

    agent = qmetagpt.PPOAgent(
    state_dim=10,
    action_dim=8,
    learning_rate=0.0003,
    n_steps=2048
)

    Methods

    build_model(policy_kwargs=None) - Initializes the PPO model with specified policy architecture - policy_kwargs: Dictionary of neural network architecture parameters

    generate_circuit(state) - Generates a quantum circuit for the given problem state - Returns: Qiskit QuantumCircuit object

    train(env, total_timesteps) - Trains the agent on the specified environment - env: Quantum circuit environment - total_timesteps: Number of training timesteps

    save(path) / load(path) - Save/load trained model to/from file

    A2CAgent

    Location: qmetagpt.quantum_algorithm_generator.agents.a2c_agent.A2CAgent

    License Required: Basic or higher

    Advantage Actor-Critic (A2C) agent for fast quantum circuit prototyping.

    Constructor

    A2CAgent(state_dim, action_dim, policy='MlpPolicy', **kwargs)

    Key Features: - Fast training convergence - Lower memory requirements - Good for initial algorithm exploration

    DDPGAgent

    Location: qmetagpt.quantum_algorithm_generator.agents.ddpg_agent.DDPGAgent

    License Required: Basic or higher

    Deep Deterministic Policy Gradient (DDPG) agent for continuous quantum parameter optimization.

    Constructor

    DDPGAgent(state_dim, action_dim, policy='MlpPolicy', **kwargs)

    Key Features: - Continuous action spaces - Good for parameter optimization - Deterministic policy output

    SACAgent

    Location: qmetagpt.quantum_algorithm_generator.agents.sac_agent.SACAgent

    License Required: Basic or higher

    Soft Actor-Critic (SAC) agent with maximum entropy reinforcement learning.

    Constructor

    SACAgent(state_dim, action_dim, policy='MlpPolicy', **kwargs)

    Key Features: - Maximum entropy exploration - Sample efficient training - Robust to hyperparameters

    QuantumEvaluator

    Location: qmetagpt.evaluation_engine.quantum_evaluator.QuantumEvaluator

    License Required: Basic (simulator), Enterprise (hardware)

    Comprehensive quantum circuit evaluation and benchmarking.

    Constructor

    QuantumEvaluator(use_hardware=False, backend_name='aer_simulator')

    Parameters: - use_hardware (bool): Whether to use real quantum hardware - backend_name (str): Quantum backend identifier

    Methods

    evaluate(circuit, shots=1024) - Evaluates quantum circuit performance - Returns: Dictionary with fidelity, counts, execution time, etc.

    Example: 

    evaluator = qmetagpt.QuantumEvaluator()
results = evaluator.evaluate(circuit, shots=2048)
print(f"Fidelity: {results['fidelity']:.4f}")

    Core Functions

    get_agent

    Location: qmetagpt.quantum_algorithm_generator.agent_registry.get_agent

    License Required: Basic or higher

    Factory function for creating RL agents by name.

    def get_agent(agent_name, state_dim, action_dim, **kwargs)

    Parameters: - agent_name (str): Agent type ("PPO", "A2C", "DDPG", "SAC") - state_dim (int): State space dimension - action_dim (int): Action space dimension - **kwargs: Agent-specific parameters

    Example: 

    agent = qmetagpt.get_agent("PPO", state_dim=10, action_dim=8)

    Location: qmetagpt.licensing.get_machine_id

    Generates unique machine identifier for license binding.

    def get_machine_id() -> str

print(f"Machine ID: {machine_id}")

    License Decorators

    @licensed_class

    Location: qmetagpt.licensing.licensed_class

    Class decorator that enforces license validation on instantiation and methods.

    @licensed_class(features=None, protect_all_methods=True, exclude_methods=None)
def decorator(cls): ...

    Parameters: - features (List[str]): Required license features - protect_all_methods (bool): Protect all public methods - exclude_methods (List[str]): Methods to exclude from protection

    Example: 

    @licensed_class(features=['core'], protect_all_methods=True)
class MyQuantumAlgorithm:
    def __init__(self):
        # License validation happens here
        pass

    @require_license

    Location: qmetagpt.licensing.require_license

    Function decorator for license-protected functions.

    @require_license(features=None)
def decorator(func): ...

    Example: 

    @require_license(features=['pro'])
def advanced_optimization():
    # Pro license required
    pass

    @licensed_method

    Location: qmetagpt.licensing.licensed_method

    Method decorator for license-protected class methods.

    @licensed_method(features=None)
def decorator(method): ...

    Example: 

    class QuantumProcessor:
    @licensed_method(features=['enterprise'])
    def enterprise_feature(self):
        # Enterprise license required
        pass

    Usage Examples

    Basic Agent Creation

    import qmetagpt

# Create PPO agent for quantum circuit generation
agent = qmetagpt.PPOAgent(
    state_dim=10,
    action_dim=8,
    policy='MlpPolicy'
)

# Build the model with custom architecture
agent.build_model(
    policy_kwargs=dict(
        net_arch=[128, 128, 64],
        activation_fn='tanh'
    )
)

    Agent Registry Usage

    # Get agent by name
agent = qmetagpt.get_agent(
    agent_name="PPO",
    state_dim=12,
    action_dim=6,
    learning_rate=0.0003
)

# Available agents: "PPO", "A2C", "DDPG", "SAC"

    Quantum Evaluation

    # Initialize evaluator for simulation
evaluator = qmetagpt.QuantumEvaluator(
    use_hardware=False,
    backend_name='aer_simulator'
)

# Evaluate quantum circuit
results = evaluator.evaluate(
    circuit=quantum_circuit,
    shots=1024
)

# Access results
fidelity = results['fidelity']
counts = results['counts']
execution_time = results['execution_time']

    Hardware Evaluation (Enterprise License)

    # Initialize for IBM Quantum hardware
evaluator = qmetagpt.QuantumEvaluator(
    use_hardware=True,
    backend_name='ibmq_manila'
)

# Note: Requires valid IBMQ credentials and Enterprise license
results = evaluator.evaluate(circuit, shots=512)

    Error Handling

    License Validation Errors

    All core functions will raise LicenseEnforcementError if license validation fails:

    try:
    agent = qmetagpt.PPOAgent(state_dim=10, action_dim=5)
except qmetagpt.LicenseEnforcementError as e:
    print(f"License error: {e}")
    print(f"Machine ID: {qmetagpt.get_machine_id()}")
    print("Contact: bajpaikrishna715@gmail.com")

    Agent Creation Errors

    try:
    agent = qmetagpt.get_agent("INVALID_AGENT", 10, 5)
except ValueError as e:
    print(f"Agent error: {e}")
    # Available agents: PPO, A2C, DDPG, SAC

    Evaluation Errors

    try:
    results = evaluator.evaluate(invalid_circuit)
except Exception as e:
    print(f"Evaluation failed: {e}")
    # Check circuit validity and backend availability

    Configuration

    Global Configuration

    import qmetagpt

# Set global configuration
qmetagpt.config.set_backend('aer_simulator')
qmetagpt.config.set_shots(2048)
qmetagpt.config.set_log_level('INFO')

    Agent Configuration

    # PPO-specific configuration
ppo_config = {
    'learning_rate': 0.0003,
    'n_steps': 2048,
    'batch_size': 64,
    'n_epochs': 10,
    'gamma': 0.99,
    'gae_lambda': 0.95,
    'clip_range': 0.2,
    'ent_coef': 0.0,
    'vf_coef': 0.5
}

agent = qmetagpt.PPOAgent(state_dim=10, action_dim=5, **ppo_config)

    Evaluator Configuration

    # Advanced evaluator configuration
evaluator = qmetagpt.QuantumEvaluator(
    use_hardware=False,
    backend_name='aer_simulator',
    noise_model=None,
    optimization_level=1,
    shots=1024,
    memory=True,
    max_parallel_threads=1
)

    Performance Tips

    Memory Optimization

    # Use smaller networks for memory-constrained environments
agent = qmetagpt.PPOAgent(
    state_dim=8,
    action_dim=4,
    policy_kwargs=dict(
        net_arch=[32, 32],          # Smaller network
        share_features_extractor=True
    )
)

    Parallel Processing

    # Enable parallel environments for faster training
agent = qmetagpt.PPOAgent(
    state_dim=10,
    action_dim=5,
    n_envs=4,  # 4 parallel environments
    device='cuda' if torch.cuda.is_available() else 'cpu'
)

    Batch Evaluation

    # Evaluate multiple circuits efficiently
circuits = [circuit1, circuit2, circuit3]
results = evaluator.batch_evaluate(circuits, shots=1024)

    Thread Safety

    QuantumMetaGPT core components are thread-safe for read operations but not for concurrent modifications:

    import threading

# Safe: Multiple threads reading
def evaluate_worker(circuit):
    return evaluator.evaluate(circuit)

threads = [
    threading.Thread(target=evaluate_worker, args=(circuit,))
    for circuit in circuits
]

# Unsafe: Concurrent agent training
# Use separate agent instances for concurrent training

    import logging
logging.basicConfig(level=logging.DEBUG)

# Now all QuantumMetaGPT operations will show debug info
agent = qmetagpt.PPOAgent(state_dim=10, action_dim=5)
