    Configuration Guide

    QuantumMetaGPT provides flexible configuration options for customizing behavior, performance, and integration settings.

    Configuration Methods

    1. Environment Variables

    Set configuration through environment variables:

    # Core settings
export QUANTUMMETA_LOG_LEVEL=INFO
export QUANTUMMETA_BACKEND=aer_simulator
export QUANTUMMETA_SHOTS=1024

# API Keys (Pro/Enterprise)
export OPENAI_API_KEY=your_openai_key
export IBMQ_API_TOKEN=your_ibm_token

# Licensing
export QUANTUMMETA_LICENSE_PATH=/path/to/license.qkey
export QUANTUMMETA_MACHINE_ID=auto

    2. Configuration File

    Create qmetagpt_config.yaml:

    # QuantumMetaGPT Configuration File
# Global Settings
global:
  log_level: INFO
  backend: aer_simulator
  shots: 1024
  max_workers: 4

# Quantum Computing Settings
quantum:
  default_backend: aer_simulator
  simulator_method: statevector
  noise_model: null
  optimization_level: 1
  max_qubits: 20
  shots: 1024
  memory: true

# RL Training Configuration
reinforcement_learning:
  default_agent: PPO
  training:
    total_timesteps: 50000
    learning_rate: 0.0003
    batch_size: 64
    n_steps: 2048
    gamma: 0.99
    gae_lambda: 0.95

  policy:
    net_arch: [128, 128, 64]
    activation_fn: tanh
    share_features_extractor: false

# LLM Integration (Pro/Enterprise)
llm:
  provider: openai
  model: gpt-4
  max_tokens: 2048
  temperature: 0.7
  timeout: 30
  retry_attempts: 3

# Optimization Settings (Pro/Enterprise)
optimization:
  default_optimizer: COBYLA
  max_iterations: 1000
  tolerance: 1e-6
  options:
    COBYLA:
      rhobeg: 1.0
      rhoend: 1e-4
    SPSA:
      maxiter: 1000
      a: 0.602
      c: 0.101

# Evaluation Settings
evaluation:
  default_shots: 1024
  measurement_error_mitigation: false
  readout_error_mitigation: false
  timeout: 300

# Reporting Configuration
reporting:
  output_format: pdf
  include_visualizations: true
  latex_engine: pdflatex
  figure_dpi: 300
  max_circuit_width: 20

# Web API Settings (Enterprise)
api:
  host: 127.0.0.1
  port: 8000
  workers: 4
  timeout: 60
  cors_origins: ["*"]

# Security and Licensing
security:
  license_check_interval: 3600  # seconds
  strict_validation: true
  machine_id_validation: true

# Performance Settings
performance:
  parallel_processing: true
  max_parallel_threads: 4
  memory_limit_gb: 8
  cache_enabled: true
  cache_size_mb: 512

    3. Programmatic Configuration

    Configure settings directly in Python:

    import qmetagpt

# Global configuration
qmetagpt.config.set_backend('aer_simulator')
qmetagpt.config.set_shots(2048)
qmetagpt.config.set_log_level('DEBUG')

# Component-specific configuration
agent_config = {
    'learning_rate': 0.0003,
    'batch_size': 128,
    'net_arch': [256, 256, 128],
    'activation_fn': 'relu'
}

evaluator_config = {
    'shots': 2048,
    'optimization_level': 2,
    'memory': True
}

# Apply configurations
agent = qmetagpt.PPOAgent(state_dim=10, action_dim=8, **agent_config)
evaluator = qmetagpt.QuantumEvaluator(**evaluator_config)

    Loading Configurations

    Configuration Priority

    QuantumMetaGPT loads configuration in this order (highest priority first):

    1. Programmatic settings (qmetagpt.config.set_*())
    2. Environment variables (QUANTUMMETA_*)
    3. Local config file (./qmetagpt_config.yaml)
    4. User config file (~/.qmetagpt/config.yaml)
    5. System config file (/etc/qmetagpt/config.yaml)
    6. Default values

    Loading Custom Configs

    import qmetagpt

# Load specific configuration file
qmetagpt.config.load_config('custom_config.yaml')

# Load multiple configs (later ones override earlier)
qmetagpt.config.load_configs([
    'base_config.yaml',
    'environment_config.yaml',
    'user_overrides.yaml'
])

# Validate configuration
if not qmetagpt.config.validate():
    print("Configuration validation failed")
    exit(1)

    Configuration Validation

    Schema Validation

    import qmetagpt

# Validate current configuration
validation_result = qmetagpt.config.validate()

if not validation_result.is_valid:
    print("Configuration errors found:")
    for error in validation_result.errors:
        print(f"  - {error.path}: {error.message}")

    Runtime Validation

    # Check if configuration supports requested features
if qmetagpt.config.has_feature('llm_integration'):
    llm = qmetagpt.LLMProcessor()
else:
    print("LLM integration not configured")

# Validate license requirements
if not qmetagpt.config.validate_license(['pro']):
    print("Pro license required for this configuration")

    Best Practices

    1. Environment Separation

    # Development
export QUANTUMMETA_CONFIG_ENV=development

# Production  
export QUANTUMMETA_CONFIG_ENV=production

# Testing
export QUANTUMMETA_CONFIG_ENV=testing

    2. Secure Credential Management

    # Don't put secrets in config files
llm:
  api_key_env: OPENAI_API_KEY  # Reference environment variable

quantum:
  ibmq_token_env: IBMQ_API_TOKEN  # Reference environment variable

    3. Configuration Templates

    # Create configuration templates
def create_research_config():
    return {
        'quantum': {'shots': 4096},
        'rl': {'total_timesteps': 100000},
        'optimization': {'max_iterations': 2000}
    }

def create_development_config():
    return {
        'quantum': {'shots': 256},
        'rl': {'total_timesteps': 1000},
        'optimization': {'max_iterations': 100}
    }

# Apply template
config = create_research_config()
qmetagpt.config.update(config)

    4. Configuration Monitoring

    # Monitor configuration changes
@qmetagpt.config.on_change
def config_changed(key, old_value, new_value):
    print(f"Configuration changed: {key} = {new_value}")

# Log current configuration
qmetagpt.config.log_current_config()

    Troubleshooting

    Configuration Issues

    # Debug configuration loading
qmetagpt.config.debug_loading = True

# Check configuration sources
print("Config sources:", qmetagpt.config.get_sources())

# Validate specific sections
print("Quantum config valid:", qmetagpt.config.validate_section('quantum'))

    Common Problems

    Invalid backend specified 

    # Check available backends
print("Available backends:", qmetagpt.get_available_backends())

    License configuration issues 

    # Debug license configuration
print("License path:", qmetagpt.config.get('security.license_path'))
print("Machine ID:", qmetagpt.get_machine_id())

    Memory/Performance issues 

    # Check resource limits
print("Memory limit:", qmetagpt.config.get('performance.memory_limit_gb'))
print("Max workers:", qmetagpt.config.get('performance.max_workers'))

    This configuration guide provides comprehensive control over QuantumMetaGPT behavior. Always validate configurations before production use and maintain separate configs for different environments.
