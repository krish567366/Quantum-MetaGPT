    Deployment Guide

    Overview

    This guide covers deploying QuantumMetaGPT documentation to GitHub Pages using MkDocs Material theme.

    Prerequisites

    • Python 3.10+ with QuantumMetaGPT installed
    • Git repository on GitHub
    • GitHub account with Pages enabled
    • MkDocs and required dependencies

    Setup

    1. Install Documentation Dependencies

    pip install mkdocs mkdocs-material mkdocstrings mkdocstrings-python

    2. Verify MkDocs Configuration

    The mkdocs.yml file should be properly configured:

    site_name: QuantumMetaGPT Documentation
site_description: Autonomous Quantum AI Research Agent
theme:
  name: material
  palette:
    - scheme: default
      primary: deep purple
      accent: purple

    3. Test Local Build

    # Build documentation locally
mkdocs build

# Serve locally for testing
mkdocs serve

    Visit http://127.0.0.1:8000 to preview the documentation.

    GitHub Pages Deployment

    Method 1: GitHub Actions (Recommended)

    Create .github/workflows/docs.yml:

    name: Deploy Documentation

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
    - name: Checkout
      uses: actions/checkout@v4

    - name: Setup Python
      uses: actions/setup-python@v4
      with:
        python-version: '3.10'

    - name: Install dependencies
      run: |
        pip install mkdocs mkdocs-material mkdocstrings mkdocstrings-python

    - name: Build documentation
      run: mkdocs build

    - name: Setup Pages
      uses: actions/configure-pages@v3

    - name: Upload artifact
      uses: actions/upload-pages-artifact@v2
      with:
        path: site/

  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    if: github.ref == 'refs/heads/main'
    steps:
    - name: Deploy to GitHub Pages
      id: deployment
      uses: actions/deploy-pages@v2

    Method 2: Manual Deployment

    # Build and deploy manually
mkdocs gh-deploy --force

def build_and_deploy():
    """Build and deploy documentation"""
    try:
        # Build documentation
        subprocess.run(["mkdocs", "build"], check=True)
        print("✅ Documentation built successfully")

        # Deploy to GitHub Pages
        subprocess.run(["mkdocs", "gh-deploy", "--force"], check=True)

    Add documentation validation to .pre-commit-config.yaml:

  hooks:
  - id: mkdocs-build
    name: MkDocs build test
    entry: mkdocs build --strict
    language: system
    files: ^(docs/|mkdocs\.yml)
    pass_filenames: false

    Quality Assurance

    1. Link Checking

    Install and use markdown link checker:

    npm install -g markdown-link-check

# Check all markdown files
find docs -name "*.md" -exec markdown-link-check {} \;

    2. Documentation Linting

    Use markdownlint:

    npm install -g markdownlint-cli

# Lint all documentation
markdownlint docs/**/*.md

    3. Build Validation

    Validate documentation builds without errors:

    # Strict build - fails on warnings
mkdocs build --strict

# Check for broken links
mkdocs serve &
SERVER_PID=$!
sleep 5
curl -f http://127.0.0.1:8000 || echo "Build validation failed"
kill $SERVER_PID

    Common Issues

    Build Failures 

    # Check MkDocs version
mkdocs --version

# Validate configuration
mkdocs build --strict --verbose

    Missing Dependencies 

    # Install all required packages
pip install -r docs/requirements.txt

    GitHub Pages Not Updating - Check Actions tab for build errors - Verify Pages settings in repository - Clear browser cache
