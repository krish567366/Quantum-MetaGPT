    Installation Guide

    Prerequisites

    System Requirements

    • Operating System: Windows 10+, macOS 10.15+, or Linux (Ubuntu 18.04+)
    • Python: 3.10 or higher
    • Memory: Minimum 8GB RAM (16GB recommended)
    • Storage: 2GB free disk space

    Dependencies

    QuantumMetaGPT requires the following major dependencies:

    • Qiskit 0.44+ - Quantum computing framework
    • Stable-Baselines3 2.0+ - Reinforcement learning library
    • PyTorch 2.0+ - Deep learning framework
    • FastAPI 0.95+ - Web framework
    • OpenAI - LLM integration
    • Transformers - Hugging Face transformers

    Installation Methods

    Method 1: pip Installation (Recommended)

    pip install quantummetagpt

    Method 2: Development Installation

    Clone the repository and install in development mode:

    git clone https://github.com/yourusername/QuantumMetaGPT.git
cd QuantumMetaGPT
pip install -e .

    Method 3: Conda Installation

    conda install -c conda-forge quantummetagpt

    License Activation

    QuantumMetaGPT requires a valid license to operate. After installation:

    1. Get Your Machine ID

    import qmetagpt
machine_id = qmetagpt.get_machine_id()
print(f"Your Machine ID: {machine_id}")

    2. Contact for License

    Email bajpaikrishna715@gmail.com with:

    • Your machine ID
    • Desired license tier (Basic/Pro/Enterprise)
    • Intended use case

    3. Activate License

    Once you receive your license file:

    quantum-license activate your-license.qkey

    Verification

    Verify your installation:

    import qmetagpt

# Check license status
qmetagpt.show_license_info()

# Test basic functionality
agent = qmetagpt.PPOAgent(state_dim=5, action_dim=3)
print("✅ QuantumMetaGPT installed successfully!")

    Configuration

    Environment Variables

    Create a .env file in your project directory:

    # OpenAI API Key (for Pro/Enterprise licenses)
OPENAI_API_KEY=your_openai_api_key

# IBM Quantum API Token (optional)
IBMQ_API_TOKEN=your_ibm_quantum_token

# Logging Level
LOG_LEVEL=INFO

# Quantum Backend Preference
QUANTUM_BACKEND=aer_simulator

    Configuration File

    Create qmetagpt_config.yaml:

    # QuantumMetaGPT Configuration
quantum:
  backend: "aer_simulator"
  shots: 1024
  max_qubits: 20

rl_training:
  total_timesteps: 10000
  learning_rate: 0.0003
  batch_size: 64

llm:
  model: "gpt-4"
  max_tokens: 2048
  temperature: 0.7

optimization:
  method: "COBYLA"
  max_iterations: 1000
  tolerance: 1e-6

reporting:
  format: "pdf"
  include_visualizations: true
  latex_engine: "pdflatex"

    Troubleshooting

    Common Issues

    License Validation Fails

    🚫 QUANTUMMETAGPT LICENSE ERROR
📋 No valid QuantumMetaGPT license found

    Solution: Ensure your license is properly activated and your machine ID matches.

    Import Errors

    ImportError: No module named 'qiskit'

    Solution: Install missing dependencies: 

    pip install qiskit>=0.44 stable-baselines3>=2.0

    Memory Issues

    RuntimeError: CUDA out of memory

    Solution: Reduce batch size in configuration or use CPU mode: 

    import torch
torch.cuda.empty_cache()

    Platform-Specific Issues

    Windows

    • Install Microsoft Visual C++ Build Tools if compilation fails
    • Use PowerShell or Command Prompt as administrator

    macOS

    • Install Xcode command line tools: xcode-select --install
    • For M1/M2 Macs, use native Python installation

    Linux

    • Install build essentials: sudo apt-get install build-essential
    • Ensure CUDA drivers are properly installed for GPU support

    Docker Installation

    Using Pre-built Image

    docker pull quantummetagpt/quantummetagpt:latest
docker run -it --rm quantummetagpt/quantummetagpt:latest

    Building from Source

    FROM python:3.10

# Copy project files
COPY . /app
WORKDIR /app

# Install dependencies
RUN pip install -e .

# Set environment variables
ENV QUANTUMMETA_LICENSE_PATH=/app/license.qkey

# Expose API port
EXPOSE 8000

CMD ["uvicorn", "qmetagpt.frontend_interface.app:app", "--host", "0.0.0.0", "--port", "8000"]

    Build and run:

    docker build -t quantummetagpt .
docker run -p 8000:8000 -v /path/to/license.qkey:/app/license.qkey quantummetagpt

    Performance Optimization

    GPU Acceleration

    For NVIDIA GPUs:

    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

    Verify GPU availability:

    import torch
print(f"CUDA available: {torch.cuda.is_available()}")
print(f"CUDA devices: {torch.cuda.device_count()}")

    Multi-Processing

    Configure parallel processing:

    import qmetagpt

# Set number of parallel workers
qmetagpt.config.set_workers(4)

# Enable multiprocessing for RL training
agent = qmetagpt.PPOAgent(
    state_dim=10, 
    action_dim=5,
    n_envs=4  # Parallel environments
)
