    QuantumMetaGPT Licensing Guide

    Overview

    QuantumMetaGPT implements comprehensive license protection using the QuantumMeta License Server. Every class and major function is protected with license validation to ensure authorized usage.

    License Tiers

    Basic License (core features)

    • Core quantum algorithm generation
    • Basic RL agents (PPO, A2C, DDPG, SAC)
    • Quantum circuit evaluation
    • Basic reporting functionality

    Pro License (pro features)

    • All Basic features
    • LLM integration for paper parsing
    • Advanced optimization engines
    • ArXiv paper processing
    • Enhanced report generation

    Enterprise License (enterprise features)

    • All Pro features
    • REST API access
    • Commercial usage rights
    • Priority support
    • Advanced analytics

    Implementation Details

    Class-Level Protection

    All major classes are protected with the @licensed_class decorator:

    from qmetagpt.licensing import licensed_class

@licensed_class(features=['core'], protect_all_methods=True)
class QuantumAlgorithmGenerator:
    def __init__(self):
        # License validation happens automatically
        pass

    Function-Level Protection

    Individual functions can be protected with @require_license:

    from qmetagpt.licensing import require_license

@require_license(features=['pro'])
def parse_arxiv_paper(paper_id: str):
    # Advanced functionality requiring pro license
    pass

    License Enforcement

    No Grace Period

    QuantumMetaGPT enforces strict license validation with no grace period. All functionality requires a valid, active license.

    No Bypass Mechanisms

    • No development mode
    • No offline bypass
    • No debug overrides
    • Comprehensive protection across all classes

    Machine ID Binding

    Each license is bound to a unique machine identifier generated from:

    • Platform information
    • MAC address
    • Processor details
    • System node information

    Error Handling

    When license validation fails, users receive detailed error messages:

    Getting License Information

    Check your current license status:

    import qmetagpt
qmetagpt.show_license_info()

    Get your machine ID:

    from qmetagpt.licensing import get_machine_id
print(f"Machine ID: {get_machine_id()}")

    Technical Implementation

    Import-Time Validation

    License validation occurs immediately when importing QuantumMetaGPT:

    import qmetagpt  # License validation happens here

    Runtime Protection

    Every protected method validates license before execution:

    # This will validate license before allowing method execution
agent = qmetagpt.PPOAgent(state_dim=10, action_dim=5)
