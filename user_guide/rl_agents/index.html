    RL Agents Guide

    Overview

    QuantumMetaGPT provides several reinforcement learning agents optimized for quantum circuit generation and optimization. Each agent has unique strengths for different types of quantum tasks.

    Agent Comparison

    Agent Algorithm Strengths Best For License
    PPO Proximal Policy Optimization Stable training, sample efficient General-purpose quantum tasks Basic+
    A2C Advantage Actor-Critic Fast convergence, low memory Rapid prototyping Basic+
    DDPG Deep Deterministic Policy Gradient Continuous control Parameter optimization Basic+
    SAC Soft Actor-Critic Exploration, robustness Complex state spaces Basic+

    PPO Agent

    Overview

    The PPO (Proximal Policy Optimization) agent is the recommended choice for most quantum algorithm generation tasks. It provides stable training with good sample efficiency.

    import qmetagpt

# Initialize PPO agent
agent = qmetagpt.PPOAgent(
    state_dim=16,
    action_dim=12,
    policy='MlpPolicy'
)

# Configure hyperparameters
agent.build_model(
    policy_kwargs=dict(
        net_arch=[128, 128, 64],
        activation_fn='tanh'
    ),
    learning_rate=0.0003,
    n_steps=2048,
    batch_size=64,
    n_epochs=10,
    gamma=0.99,
    gae_lambda=0.95,
    clip_range=0.2
)

    Key Features

    • Clipped Surrogate Objective: Prevents destructive policy updates
    • Generalized Advantage Estimation: Reduces variance in policy gradients
    • Multiple Epochs: Reuses data for efficient learning
    • Adaptive Learning: Automatically adjusts to problem complexity

    Hyperparameter Guide

    # Conservative settings (stable but slower)
conservative_config = {

    A2C Agent

    Overview

    The A2C (Advantage Actor-Critic) agent provides fast training for quantum tasks where quick iteration is important.

    # Initialize A2C agent
agent = qmetagpt.A2CAgent(
    state_dim=16,
    action_dim=12,
    learning_rate=0.0007,
    n_steps=5,
    gamma=0.99,
    gae_lambda=1.0,
    ent_coef=0.01,
    vf_coef=0.25
)

    Advantages

    • Fast Convergence: Quicker initial learning than PPO
    • Lower Memory: Less memory usage during training
    • Synchronous Updates: Immediate policy updates
    • Simple Architecture: Easier to debug and modify

    Use Cases

    • Rapid prototyping of quantum algorithms
    • Educational demonstrations
    • Resource-constrained environments
    • Quick feasibility studies

    DDPG Agent

    Overview

    DDPG (Deep Deterministic Policy Gradient) excels at continuous control problems in quantum systems.

    # Initialize DDPG agent
agent = qmetagpt.DDPGAgent(
    state_dim=16,
    action_dim=12,
    learning_rate=0.001,
    buffer_size=1000000,
    learning_starts=100,
    batch_size=100,
    tau=0.005,
    gamma=0.99,
    noise_type='normal',
    noise_std=0.1
)

    Key Features

    • Deterministic Policy: Outputs specific actions rather than probabilities
    • Experience Replay: Learns from stored experiences
    • Target Networks: Stabilizes training with slowly updating targets
    • Continuous Actions: Handles continuous parameter spaces

    Applications

    • Quantum gate parameter optimization
    • Continuous variational algorithms
    • Real-time quantum control
    • Hardware calibration tasks

    SAC Agent

    Overview

    SAC (Soft Actor-Critic) incorporates maximum entropy to encourage exploration, making it excellent for complex quantum optimization landscapes.

    # Initialize SAC agent
agent = qmetagpt.SACAgent(
    state_dim=16,
    action_dim=12,
    learning_rate=0.0003,
    buffer_size=1000000,
    learning_starts=100,
    batch_size=256,
    tau=0.005,
    gamma=0.99,
    ent_coef='auto'  # Automatic entropy coefficient tuning
)

    Advantages

    • Maximum Entropy: Encourages diverse exploration
    • Sample Efficiency: High data efficiency
    • Robust Training: Less sensitive to hyperparameters
    • Automatic Tuning: Self-adjusting entropy coefficient

    Training Workflows

    Basic Training Pipeline

    def train_quantum_agent(agent_type="PPO", task_config=None):
    # Initialize environment
    env = qmetagpt.QuantumCircuitEnv(**task_config)

    # Create agent
    agent = qmetagpt.get_agent(
        agent_name=agent_type,
        state_dim=env.state_dim,
        action_dim=env.action_dim
    )

    # Build model
    agent.build_model()

    # Train agent
    print(f"Training {agent_type} agent...")
    agent.train(env, total_timesteps=50000)

    # Save trained model
    agent.save(f"trained_{agent_type.lower()}_agent.zip")

    return agent

    import optuna

def optimize_hyperparameters(agent_type="PPO", n_trials=100):
    def objective(trial):
        # Suggest hyperparameters

        if agent_type == "PPO":

            n_epochs = trial.suggest_int('n_epochs', 4, 20)

                state_dim=16, action_dim=12,

                clip_range=clip_range,

        # Train and evaluate
        env = qmetagpt.QuantumCircuitEnv()
        agent.build_model()
        agent.train(env, total_timesteps=10000)

        # Return performance metric
        return evaluate_agent_performance(agent, env)

    # Run optimization

    Multi-Agent Ensemble

    def create_agent_ensemble():
    """Create ensemble of different agents for robust performance"""
    agents = {
        'ppo': qmetagpt.PPOAgent(state_dim=16, action_dim=12),
        'a2c': qmetagpt.A2CAgent(state_dim=16, action_dim=12),
        'sac': qmetagpt.SACAgent(state_dim=16, action_dim=12)
    }

    # Train each agent
    env = qmetagpt.QuantumCircuitEnv()
    for name, agent in agents.items():
        print(f"Training {name} agent...")
        agent.build_model()
        agent.train(env, total_timesteps=30000)

    return agents

def ensemble_predict(agents, state):
    """Use ensemble voting for circuit generation"""
    predictions = []
    for agent in agents.values():
        circuit = agent.generate_circuit(state)
        predictions.append(circuit)

    # Select best circuit based on evaluation
    evaluator = qmetagpt.QuantumEvaluator()
    best_circuit = max(predictions, 
                      key=lambda c: evaluator.evaluate(c)['fidelity'])

    return best_circuit

    def curriculum_training(agent, difficulty_levels):
    """Gradually increase problem difficulty"""
    for level, config in difficulty_levels.items():
        print(f"Training on difficulty level: {level}")

        env = qmetagpt.QuantumCircuitEnv(**config)
        agent.train(env, total_timesteps=config['timesteps'])

        # Evaluate progress
        performance = evaluate_agent(agent, env)
        print(f"Level {level} performance: {performance}")

        if performance < config['threshold']:
            print(f"Repeating level {level}")
            agent.train(env, total_timesteps=config['timesteps'])

    Transfer Learning

    def transfer_learning(source_agent, target_task):
    """Transfer learned knowledge to new quantum task"""
    # Load pre-trained agent
    source_agent.load("pretrained_model.zip")

    # Create new environment for target task
    target_env = qmetagpt.QuantumCircuitEnv(**target_task)

    # Fine-tune on target task with lower learning rate
    source_agent.learning_rate *= 0.1  # Reduce learning rate
    source_agent.train(target_env, total_timesteps=10000)

    return source_agent

    Custom Reward Shaping

    class RewardShapedEnv(qmetagpt.QuantumCircuitEnv):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)

    def calculate_reward(self, circuit, target_state):
        base_reward = super().calculate_reward(circuit, target_state)

        # Add circuit efficiency bonus
        efficiency_bonus = 1.0 / max(1, circuit.depth())

        # Add gate diversity bonus
        gate_types = len(set(gate.name for gate in circuit.data))
        diversity_bonus = gate_types / 10.0

        # Combine rewards
        total_reward = base_reward + 0.1 * efficiency_bonus + 0.05 * diversity_bonus

        return total_reward

    def monitor_training(agent, env, log_interval=1000):
    """Monitor training progress with detailed metrics"""
    metrics = {
        'episode_rewards': [],
        'policy_loss': [],
        'value_loss': [],
        'entropy': [],
        'learning_rate': []
    }

    # Custom callback for monitoring
    class MetricsCallback:
        def on_step(self, locals, globals):
            if len(locals.get('ep_info_buf', [])) > 0:
                metrics['episode_rewards'].append(
                    np.mean([ep['r'] for ep in locals['ep_info_buf']])
                )
            return True

    # Train with monitoring
    agent.train(env, total_timesteps=50000, callback=MetricsCallback())

    return metrics

    import matplotlib.pyplot as plt

def plot_training_progress(metrics):

    # Reduce network size

    Best Practices

    1. Start Simple: Begin with small networks and simple environments
    2. Monitor Training: Use callbacks to track progress
    3. Save Frequently: Save models during training
    4. Validate Results: Test on held-out quantum tasks
    5. Use Ensembles: Combine multiple agents for robustness

    Custom Neural Networks

    import torch.nn as nn

class CustomQuantumPolicy(nn.Module):
    def __init__(self, state_dim, action_dim):
        super().__init__()
        self.shared_net = nn.Sequential(
            nn.Linear(state_dim, 128),
            nn.ReLU(),
            nn.Linear(128, 128),
            nn.ReLU()
        )
        self.policy_head = nn.Linear(128, action_dim)
        self.value_head = nn.Linear(128, 1)

    def forward(self, state):
        features = self.shared_net(state)
        action_logits = self.policy_head(features)
        value = self.value_head(features)
        return action_logits, value

# Use custom network with agent
agent = qmetagpt.PPOAgent(
    state_dim=16,
    action_dim=12,
    policy_class=CustomQuantumPolicy
)
